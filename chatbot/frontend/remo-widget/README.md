# Remo AI Widget

Embeddable chatbot widget for any website.

## Setup

```bash
npm install
npm run build
```

## Embed in any website

Add this script tag to your HTML:

```html
<script src="https://your-domain.com/embed.js"></script>
```

Or initialize manually:

```html
<script src="https://your-domain.com/remo-widget.js"></script>
<script>RemoWidget.init();</script>
```

## Features

- Floating 🤖 AI icon
- Click to open/close chat
- Responsive design
- Easy embedding
